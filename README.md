One single line that makes office life funny — an entry for the
[One-Line Office Jokes](https://make.fun/bounty/u-markk-st-one-line-office-jokes-a51f2bcc)
bounty on make.fun.

## The line

> I emailed IT about the printer jam, and they replied with a PDF I was supposed to print.

88 characters, one line: the Monday-meeting, reply-all, printer-jams-at-the-worst-moment
kind of office detail, with the laugh landing in the last few words.

## How it works

`main.ts` (Node 22) writes the joke to `/output/entry.txt`, after checking
it passes the house gate: 1–199 characters, a single non-blank line.

```sh
node main.ts
```
